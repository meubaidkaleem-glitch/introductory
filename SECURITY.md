# Security Policy

## Scope
This is a small demonstration project. It currently has no network service, credential handling, or third-party runtime dependencies.

## Reporting a concern
Please do not publish sensitive exploit details or personal information in a public issue. Contact the repository owner privately through GitHub to report a suspected vulnerability.

## Good practice
- Never commit credentials or access tokens.
- Keep dependencies minimal and review any proposed additions.
- Treat all untrusted input as untrusted if the project grows beyond its current demo scope.

Security reports will be reviewed as time and project scope permit; no response-time guarantee is implied.
