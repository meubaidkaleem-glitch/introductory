# Contributing to the Beautiful Mess

Thanks for considering a contribution. This project aims to be funny on the outside and maintainable on the inside.

## Workflow
1. Open an issue for substantial changes so the idea can be discussed.
2. Create a focused branch, such as `feat/add-greeting` or `fix/typo`.
3. Keep changes small and explain why they help.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request using the template.

## Standards
- Use clear, readable Python and the standard library where practical.
- Add or update tests for behavior changes.
- Do not commit secrets, tokens, personal data, or generated junk.
- Keep humor respectful and avoid jokes targeting protected or vulnerable groups.
- Never claim a test, scan, or workflow passed unless it actually did.

## Commit messages
Prefer concise, descriptive messages, for example: `Add custom greeting option`.
